# ルール削除機能 設計概要

## 機能概要

ルール一覧画面において、各ルールのゴミ箱アイコンをクリックすることでルールを物理削除できる機能を追加する。

## ユーザーストーリー

> ルール一覧でルールを削除できる

## トリガー

| アクター | 画面 | トリガー |
|---------|------|---------|
| ユーザー | ルール一覧(rules) | ゴミ箱アイコンをクリック → 確認ダイアログで「削除」を選択 |

※ システムイベントによる自動トリガーはなし

## 機能要件

### ルール削除

- ルール一覧の各行にゴミ箱アイコンを表示
- ゴミ箱アイコンクリック時に確認ダイアログを表示
- 確認後、ルールをDBから物理削除する
- 削除されたルールのURLパターンに一致するタブをリロードする
- 削除処理中の重複実行を防止する(`deletingIds`による重複削除防止)
  - JavaScriptのシングルスレッド実行モデルにより、has()→add()の順序でも事実上アトミック
- 削除失敗時はトースト通知でエラーを表示

### 確認ダイアログ

- 「このルールを削除しますか？」等のメッセージを表示
- 「削除」「キャンセル」ボタンを表示
- 「キャンセル」選択時は何もしない

### エラーハンドリング

- 削除処理失敗時はトースト通知でユーザーに通知
- エラー発生時もUI状態は整合性を保つ
- 部分的成功時(削除成功・タブリロード失敗)はルールを一覧から削除し、エラー通知を表示
  - 例: 「ルールの削除は完了しましたが、関連するタブの再読み込みに失敗しました」
