# scripts コーディング規約

## 適用シナリオ

1. **新しいシェルスクリプトを追加する場合**: 変数名はUPPER_CASEで統一し、省略しない（例: `CHK`ではなく`CHECK_MODE`）。条件分岐ではelse句を使わずearly returnで記述し、インデントを2段階以内に保つ
2. **既存スクリプトに条件判定を追加する場合**: 同様の条件判定が既にヘルパー変数や既存ロジックとして存在しないか調査し、あれば再利用する。新たに条件判定を追加する場合も、再利用可能なヘルパー変数として定義することを検討する

## オブジェクト指向ルール（ThoughtWorksアンソロジー）

9つのルールのうち、下記3つは必ず遵守すること：

1. **1つのメソッドにつきインデントは2段階までにすること**
  - 原典では1段階までとなっているが、makeプロジェクトでは2段階まで許容する
2. **else句を使用しないこと**
  - → early returnパターンを使用すること
5. **名前を省略しないこと**

## 命名規則
- 変数名は **UPPER_CASE** （大文字スネークケース）を使用すること
  - 例: `CHECK_MODE`, `MAXIMUM_NUMBER`, `NEW_NUMBER`
  - 関数内のローカル変数も同様

## その他ルール
- if文は同様の条件判定がヘルパー変数として実装されていないか、それを再利用できないか調査すること
  - あるいは既存ロジックで同様の条件判定をしている場合、そのロジックをヘルパー変数化して再利用すること
