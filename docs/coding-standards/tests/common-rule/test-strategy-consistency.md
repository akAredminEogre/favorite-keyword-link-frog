# §7 テスト戦略書との一貫性

## 目的

テストコードとテスト戦略書の間で、テストケースの名前・順番を一致させることで、ドキュメントとコードの乖離を防ぐ。

## ルール

### 7.1 テストケース名の一致

- **JSDocのテストケース説明は、テスト戦略書のテストケース名と一致させること**
- `it()` の説明文もテスト戦略書と一致させること

### 7.2 テストケースの順番

- **テストケースの順番もテスト戦略書と一致させること**
- テスト戦略書の「テスト分類」表の順番に従う

### 7.3 更新義務

- テストケースを追加・削除した場合、テスト戦略書とテストコードの両方を更新すること
- テスト戦略書にあるがテストコードに未実装のケースがある場合は、理由を明記するか実装すること

## 適用範囲

- 単体テスト（unit）
- 結合テスト（integration）
- E2Eテスト（e2e）
