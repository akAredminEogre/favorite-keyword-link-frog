# 受け入れ条件

## ユーザーストーリー要件

- [ ] AC-1: プレビューダイアログが `ModalDialogBase` を使用して実装されている
- [ ] AC-2: ダイアログが開いたとき、フォーカスがダイアログ内の最初のフォーカス可能要素に移動する
- [ ] AC-3: ダイアログが開いている間、フォーカスがダイアログ外に出ない（フォーカストラップ）
- [ ] AC-4: Escape キーでダイアログが閉じ、フォーカスが元の要素（インポートボタン等）に戻る
- [ ] AC-5: オーバーレイ（ダイアログ外の暗くなった領域）クリックでダイアログが閉じる
- [ ] AC-6: ダイアログが閉じたとき、フォーカスがダイアログを開いた要素に復元される

## 技術要件

- [ ] AC-7: `div role="dialog"` の直接実装を廃止し、`ModalDialogBase` コンポーネントを使用している
- [ ] AC-8: ADR-007（WAI-ARIA Dialog Modal Pattern 準拠方針）に準拠している
- [ ] AC-9: `ConfirmDialog`（OK/キャンセル）との UI 挙動の一貫性が保たれている
- [ ] AC-10: 既存の E2E テスト（正常系インポートフロー）がすべて通過する
